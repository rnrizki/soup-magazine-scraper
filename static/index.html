🚀 Cara Menjalankan Skrip Python & Menghasilkan CSV

Panduan mudah untuk menjalankan skrip web scraping BeautifulSoup di komputer Anda (Windows, Mac, atau Linux).

Prasyarat: Instalasi Library Python Cukup dijalankan sekali

Pastikan komputer Anda memiliki Python dan library requests serta beautifulsoup4:

pip install requests beautifulsoup4
1

Langkah 1: Simpan / Unduh Kode

1. Buka aplikasi Text Editor (VS Code, Notepad, atau PyCharm).

2. Buat file baru dan copy-paste kode Python yang dihasilkan oleh SoupAI (atau klik tombol Unduh scraper.py pada kotak kode di chat).

3. Simpan file tersebut dengan nama scraper.py di folder yang Anda inginkan (misalnya di folder Downloads).

2

Langkah 2: Jalankan di Terminal / Command Prompt

1. Buka Terminal (Mac/Linux) atau Command Prompt / PowerShell (Windows).

2. Masuk ke folder tempat file scraper.py disimpan (contoh jika disimpan di folder Downloads):

cd Downloads

3. Jalankan skrip dengan perintah:

Windows / Umum:
python scraper.py
Mac / Linux:
python3 scraper.py
3

Langkah 3: Ambil Hasil File CSV

Setelah skrip selesai berjalan, terminal akan menampilkan pesan konfirmasi:

✨ Berhasil! Data telah disimpan ke file: 'majalah_links.csv'

File majalah_links.csv otomatis tersimpan di folder yang sama. Anda bisa langsung membukanya menggunakan:

📊 Microsoft Excel
📑 Google Sheets
📝 Text Editor / Notepad
